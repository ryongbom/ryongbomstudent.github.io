# Лабораторная работа №6: STL (Вариант 1)

## 📌 О проекте

Изучение стандартной библиотеки шаблонов (STL) C++: контейнеры, алгоритмы, ассоциативные контейнеры с пользовательскими компараторами.

---

## ✅ Выполненные задания

### **Задание 1: Контейнеры**

- **7 контейнеров**: `array`, `vector`, `list`, `set`, `map`, `multimap`, `unordered_set`
- **Инициализация**: 4+ способа (конструктор по умолчанию, список инициализации, заполняющий конструктор, копирование, `assign()`, `fill()`)
- **Операции**: вставка, удаление, поиск, изменение, копирование (с итераторами)
- **Файловый ввод/вывод**: сохранение и загрузка `vector<int>`
- **Пользовательская структура**: `Person` (фамилия, имя, возраст)

### **Задание 2: STL алгоритмы (Вариант 1)**

- **Генерация чисел**: `generate()` + `mt19937` (-10 до 10)
- **Максимум по модулю**: `max_element()` + лямбда
- **Замена отрицательных**: `replace_if()` + лямбда (отрицательные → 0)
- **Удаление дубликатов**: `unordered_set` (сохранение первого вхождения)

### **Задание 3: multiset + Functor (Вариант 1)**

- **Контейнер**: `multiset<Person, ComparePersonByAge>`
- **Компаратор**: Functor с перегрузкой `operator()` (сравнение по возрасту)
- **Операции**: `insert()`, `count()`, `find()`, `equal_range()`, `lower_bound()`, `upper_bound()`

### **Тестирование производительности**

- **Данные**: 100 000 случайных чисел
- **Измерение времени**: `chrono` (вставка, поиск)
